## 🔄 The Shift-Left Development Cycle

```
[ Requirements Analysis ] ➔ [ Typed API Contract ] ➔ [ Parallel Coding (UI + Backend) ] ➔ [ Chaos Testing (SDET) ] ➔ [ Production Ship ]
```

1. **Phase 1 (Core Interface):** Dashboard HUD, MetricCards, and hold-to-confirm failover button.
2. **Phase 2 (3D Visualizer):** Three.js 60FPS rotating wireframe Earth with Bézier data conduit connecting AWS (`us-east-1`) to GCP (`us-central1`).
3. **Phase 3 (Live Failover Mechanics):** State transitions dynamically updating the 3D conduit velocity and colors (Cyan $\to$ Amber $\to$ Emerald).
4. **Phase 4 (Backend Telemetry & E2E):** Real WebSocket connection with chaos engineering validation.
