# ✨ Vibe Coding Creations
*Crafted by Antonio Nwozo*

A curated showcase of modern, AI-assisted "vibe coding" applications, interactive dashboards, and design experiments.

---

## 📡 Project 01: NewConnect Fixed-Wireless Radio Showcase

An interactive, high-end dark-mode showcase platform for carrier-grade microwave and millimeter-wave (mmWave) wireless infrastructure.

### ⚡ Key Features
- **Carrier-Grade Hardware Catalog:** Siklu EtherHaul 8010 FX (10 Gbps E-Band), Ubiquiti AirFiber 60 XR, Mimosa, and IgniteNet.
- **Deep Technical Specs:** Dynamic modal cards inspecting frequency bands, full-duplex throughput, link budgets, and sub-10-microsecond latency profiles.
- **Modern Ambient Aesthetic:** Built with ambient glassmorphism, responsive Tailwind CSS styling, and Lucide vector icons.

### 🛠️ Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS (CDN / Utility Classes)
- **Icons:** Lucide React
- **Runtime:** Node.js LTS

---

## 🚀 Quickstart: Run Locally

```bash
# 1. Clone repository
git clone https://github.com/Anwozo157/vibe-coding-creations.git
cd vibe-coding-creations

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev
```

Visit `http://localhost:5173` to experience the site live in your browser!
